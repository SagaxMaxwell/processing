# 数据处理

示例覆盖 Kafka、Debezium CDC、Flink SQL、Spark、Iceberg 与 Kubernetes。

## 入口

| 目录 | 示例 |
| --- | --- |
| `work/kafka` | 交易事件生产与消费 |
| `work/connect` | PostgreSQL CDC |
| `work/flink` | 支付失败窗口告警 |
| `work/spark` | 批处理与实时 GMV |
| `work/lakehouse` | Iceberg 表初始化 |
| `work/kubernetes` | Spark Operator 作业 |

各目录的 `README.md` 提供命令和参数。
